# final_proyect_KODLAND
proyecto con Python, HTML y CSS
proyecto con la finalidad de reducir o concientizar sobre la huella de carbono y el cambio climatico. esté proyecto será una plataforma web con múltiples funcionalidades que permitirán al usuario adquirir una nueva perspectiva sobre el cambio climático el proyecto se apoya en HTML, CSS, Python, síntesis de voz, SQL y Flask

funciones:
cuestionario sobre el cambio climático: utilizará HTML, Flask y SQL para un análisis que devuelva el grado de contaminación que genera el usuario.
material teórico: utilizará HTML y CSS para brindarle al usuario información sobre las causas, efectos y consecuencias del cambio climático. Está función va a estar organizada en subdivisiones que organizaran la información para que el usuario pueda acceder exactamente a lo que quiera saber
calculadora de huella de carbono: utilizará Flask, Python, HTML y CSS para calcular en base a las respuestas del usuario la huella de carbono y las consecuencias que genera
presentación audiovisual: utilizará la síntesis de voz y CSS para mostrarle al usuario una presentación que hable acerca del cambio climático.
soporte bilingüe: la plataforma permitirá al usuario elegir entre el idioma inglés y el español e inclusive está funcionalidad deberá traducir la presentación audiovisual al inglés.
botón del pánico: utilizará Flask, HTML, CSS y Python. Estará diseñado para que te puedas prevenir a una catástrofe mundial, es decir, dará una lista de preparativos que podrías tener para estar preparado para distintas cátstrofes, por ejemplo, una nueva era del hielo.
